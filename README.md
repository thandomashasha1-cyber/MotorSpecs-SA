# MotorSpecs-SA

Technologies : HTML, CSS, JavaScript, Bootstrap, LocalStorage

Developed a responsive vehicle specification website focused on providing accessible information about vehicles available in the South African market.
Implemented vehicle search, brand browsing, detailed specifications, and multi-vehicle comparison functionality.
Created a responsive interface using Bootstrap and custom CSS for desktops and mobile devices
Implemented client-side functionality using JavaScript and LocalStorage for user preferences and application features
